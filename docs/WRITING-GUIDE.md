# 写作指南

本站是**金融知识科普**，不是资讯站，也不是研报。写之前先读这一页。

## 一、读者是谁

| 读者 | 特征 | 写作要求 |
|---|---|---|
| **宝妈**（第一读者） | 有闲钱、怕亏、没时间、被销售话术坑过 | 结论先行、给生活类比、说清"和我的钱有什么关系" |
| **金融小白** | 想搞懂但怕被割 | 每个术语先一句话说清，再展开 |
| **进阶用户** | 已有框架，缺数据 | 给口径、给原始序列、给分位与分布 |

**默认读者是宝妈。** 一句话如果需要金融背景才能懂，就重写。

## 二、每篇必写的四段式

术语卡固定四段，缺一段就不算写完：

| 段 | 要求 | 反例 |
|---|---|---|
| **一句话** | 不超过 40 字，不用任何未解释的术语 | "这是资产的定价基准"（"资产"没解释） |
| **比喻** | 来自读者的日常生活 | "就像给钱定一个价"（"定价"本身需要解释） |
| **数字** | 真实数值 + 口径 + 时间 | "最近涨了很多" |
| **坑** | 读者最可能踩的那个错 | "注意风险"（等于没说） |

## 三、数字纪律（最重要）

1. **每个数字都要能被验证。** 正文引用的序列必须是 `data/series-map.json` 里注册过的 id。
2. **写清楚口径。** "2008年10月黄金跌了18%" —— 是月末价还是盘中？月度收盘要写明。
3. **站内数据优先。** 站内 `data/history/` 里有的数据，优先引用它，这样读者能点开核对。
4. **不插值、不外推、不用"大约"糊弄。** 拿不到就写"这个口径拿不到"。
5. **历史与现在分开写。** "当年是这样"和"现在也是这样"是两句话，不要连成一句。

## 四、类比的纪律

历史类比是最容易翻车的地方。

**必须写清楚三件事：**
1. 像在哪里（几个维度相似）
2. **不像在哪里**（关键差异，至少列一条）
3. 样本量与制度差异

**禁止：**
- ❌ "历史会重演" / "这次和上次一样"
- ❌ 只讲相似不讲差异
- ❌ 给出"接下来会怎样"的结论

**推荐句式：**
> 在估值、参与广度、盈利兑现三个维度上像 2000 年，但在流动性和产业结构上明显不同。历史样本 N=5，制度环境也不同。

## 五、免责声明

三个位置，缺一不可：

1. 文首提示条（`views/*.js` 里的 `.disclaimer`）
2. 文末（由模板统一插入）
3. 每页页脚

**不写**："本文不构成投资建议"就完事。要说清**为什么**不构成：只讲机制和历史，不预测，不给仓位建议。

## 六、禁用表达

| 不要写 | 改成 |
|---|---|
| 众所周知 | （直接说，或给出数据来源） |
| 业内人士认为 | （给出具体来源和日期） |
| 必将 / 一定会 | 可能 / 历史上曾 |
| 稳赚 / 保本 / 无风险 | （写清风险来自哪里） |
| 建议买入 / 可以考虑 | （只描述机制，不给动作） |
| 大概 / 差不多 | 写具体数值和口径 |

## 七、术语引用

正文里用 `[[术语id|显示文本]]` 引用术语，编译时会变成可点开抽屉的锚点。

- id 必须存在于 `content/_meta/glossary.json`（CI 会校验）
- 术语库里没有的词，先补进术语库再引用
- 术语库里的 JSON **字符串里要引号时用中文引号「」**，直引号会破坏 JSON

## 八、提交前自检

- [ ] 四个词条都齐了（一句话 / 比喻 / 数字 / 坑）
- [ ] 所有数字有口径、有来源、有时间
- [ ] 类比写了"不像"的部分和样本量
- [ ] 没有荐股、荐仓、预测
- [ ] 免责声明在三个位置
- [ ] 链接的术语 id 都存在
- [ ] `node _scripts/build-content.mjs` 后 `data/content/` 有更新
- [ ] `node _test/run-all.mjs` 全绿
- [ ] 通读一遍：假设读者第一次看到这个词，ta 读得懂吗

## 九、frontmatter 字段

```yaml
---
id: crisis-2008          # 必填，全站唯一
section: crisis          # 必填：concepts|assets|crisis|chains|cycles|family
title: 2008 年那场金融危机，到底发生了什么
dek: 一句话说清这篇讲什么
tag: 危机复盘            # 列表页右侧显示
tags: [2008, 次贷, 美债]
readMinutes: 12
difficulty: 3            # 1-5
dataAsOf: 2026-10-21     # 数据截止日期，必填
updatedAt: 2026-10-21
source: 东方财富 / CBOE / 美国财政部
range: 2006 – 2010       # 危机类用
points:                  # 本文的要点，文章头会渲染成清单
  - 第一句要点
  - 第二句要点
related: [risk-free-rate, gold]
---
```

**`dataAsOf` 必填。** 读者要知道这批数据是什么时候的。
