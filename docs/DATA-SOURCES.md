# 数据源

全部免密钥。浏览器直连国内源，海外源由采集脚本落成静态 JSON——**国内访问不受影响**。

## 一、实时行情（浏览器直连）

| 端点 | 用途 | 备注 |
|---|---|---|
| `https://push2.eastmoney.com/api/qt/ulist.np/get` | 报价条 + 首页仪表 + 产业链成分股 | 一次请求拿全 10 个品种；`f1`=小数位，`f2/10^f1`=价格，`f3/100`=涨跌幅 |

## 二、长历史（采集脚本 → 静态 JSON）

`node _scripts/collect-history.mjs` 产出，产物提交进仓库，浏览器只读 `data/history/*.json`。

| 序列 | 来源 | 频率 | 覆盖 | 口径 |
|---|---|---|---|---|
| `SPX` | 东财 `push2his` | 月 | 1986-03 → 今 | 月收盘价 |
| `NDX` | 东财 `push2his` | 月 | 1991-08 → 今 | 月收盘价 |
| `SH000001` | 东财 `push2his` | 月 | 1990-12 → 今 | 月收盘价 |
| `GC00Y` | 东财 `push2his` | 月 | 1990-01 → 今 | 月收盘价 |
| `SI00Y` | 东财 `push2his` | 月 | 2011-07 → 今 | 月收盘价 |
| `CL00Y` | 东财 `push2his` | 月 | 1986-09 → 今 | 月收盘价 |
| `UDI` | 东财 `push2his` | 月 | 1986-01 → 今 | 月收盘价 |
| `VIX` | **CBOE 官方** `VIX_History.csv` | 月 | 1990-01 → 今 | 月末值 |
| `US10Y` `US2Y` `US3M` `US30Y` | **美国财政部官方** `daily-treasury-rates.csv` | 月 | 1990-01 → 今 | 当月最后一个公布值 |

**为什么用官方源做 VIX 和美债**：东财对应 secid 的 K 线是空的，而这两个序列是本站"危机复盘"的支柱（VIX 衡量恐慌、美债收益率衡量信用定价），不能凑合。

**财政部 CSV 的坑**：表头带引号（`Date,"1 Mo","3 Mo",...`），解析时必须剥掉引号再找列，否则整列找不到。

**CBOE CSV 的坑**：末尾有脏行（月份为 31 之类的非法日期），必须校验月 1–12、日 1–31 再收。

## 三、危机回放包

`data/history/crisis-2008.json` 由采集脚本组合而成：

```json
{
  "id": "2008",
  "title": "2008 年次贷危机",
  "from": "2006-01-01", "to": "2010-12-31", "freq": "M",
  "dates": ["2006-01-31", "..."],          // 规范月频轴
  "series": [{ "key": "SPX", "name": "标普500", "points": [{"t":"...","v":123}] }],
  "events": [{ "t": "2008-09-15", "title": "雷曼兄弟破产", "note": "..." }],
  "source": "东方财富（指数/商品）· CBOE（VIX）· 美国财政部（美债收益率）"
}
```

**所有序列统一到月末口径**（各源原始日期不同：东财是月末，财政部是当月首个公布日）。不统一的话时间轴会出现一个月两个点，滑块会跳。

## 四、产业链成分股

`data/chain-secids.json`：`symbol → { name, secid }`，177 只全部解析成功。

采集时对美股依次试 `105/106/107` 三个市场前缀，取返回非空的那个。

## 五、序列注册表

`data/series-map.json` 是**唯一事实源**：每条序列的 id、名称、单位、频率、来源、起止日期、点数。

**正文只能引用注册表里的 id。** 杜绝"临时抓一个数就写进文章"——那种数字读者无法核对，也无法随采集更新。

## 六、已知不可用

| 源 | 状态 | 原因 / 替代 |
|---|---|---|
| FRED `fred.stlouisfed.org` | 本机网络不可达 | 已由财政部 CSV + CBOE CSV 完全替代 |
| Stooq | 403 Access denied | 已由东财 `push2his` 覆盖同类需求 |
| 东方财富 `171.*` 的历史 K 线 | 返回空数组 | 用财政部官方 CSV |

## 七、降级链

```
主源成功 → 正常显示，标数据源名
主源失败 → localStorage 缓存 + "降级"角标 + 缓存时间
缓存也没有 → 显示 "--"，绝不白屏
```

**内容页不等行情。** 行情源慢或不可达时，内容照常渲染，报价条显示"行情加载中"或"暂不可用"。

## 八、更新

GitHub Actions 每天跑一次 `collect-history.mjs` + `build-content.mjs`，有变化就提交。也可以本地跑：

```bash
node _scripts/collect-history.mjs                  # 全量
node _scripts/collect-history.mjs --only=treasury  # 只跑某一环
```

`--only` 可选值：`east`、`vix`、`treasury`、`crisis`、`chain`。
